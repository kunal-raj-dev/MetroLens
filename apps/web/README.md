# Nirikshak Web UI (`apps/web`)

## Purpose
Provides the inspector portal and officer review workstation for Nirikshak.
Enables field inspectors to upload package photographs, view bounding box overlays of extracted declarations and optical fiducials, override false alarms with written justifications, and download signed PDF dossiers.

## Owner
Frontend Lead

## Tech Stack
- Next.js (App Router)
- React 18/19 + TypeScript
- Tailwind CSS
- Lucide React Icons
