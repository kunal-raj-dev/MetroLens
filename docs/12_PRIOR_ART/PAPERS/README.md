# Academic Literature & Research Papers Repository

## Purpose
Archives abstracts, evaluation notes, and citation references for peer-reviewed academic papers in computer vision, scene text detection, and camera calibration.

## Key Monitored Publications
1. **DBNet (Liao et al., 2020):** Real-time scene text detection using differentiable binarization.
2. **SVTR (Du et al., 2022):** Single visual model for scene text recognition.
3. **Zhang's Camera Calibration (Zhang, 2000):** A flexible new technique for camera calibration.
4. **CRAFT (Baek et al., 2019):** Character region awareness for text detection.
