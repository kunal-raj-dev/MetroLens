# Model Evaluation & Benchmark Metrics

## Purpose
Defines the empirical evaluation protocols, statistical metrics, ground-truth methodologies, and test splits used to evaluate all computer vision and OCR models.

## Scope
Covers text detection (DBNet), text recognition (CRNN/SVTR), PDP segmentation, and field extraction models.

## Authoritative Inputs
- ICDAR Robust Reading benchmark standards.
- COCO evaluation metrics for segmentation.

## Assumptions
- No model performance metric may be cited in documentation or judging materials unless generated by an actual experiment recorded in `benchmarks/results/`.

## Standard Benchmark Metrics

1. **Text Detection:**
   - Precision ($P$), Recall ($R$), and F-score ($F_1$) calculated at Intersection-over-Union $\text{IoU} \ge 0.50$ and $\ge 0.75$.

2. **Text Recognition:**
   - Character Error Rate (CER): $\text{CER} = \frac{S + D + I}{N_{\text{chars}}}$
   - Word Error Rate (WER): $\text{WER} = \frac{S_w + D_w + I_w}{N_{\text{words}}}$
   - Exact Sequence Match Accuracy (Normalized Levenshtein similarity $= 1.0$).

3. **PDP Segmentation:**
   - Mean Intersection-over-Union (mIoU) between predicted PDP polygon and manual ground truth polygon.
   - Percentage Area Deviation: $\Delta A\% = \frac{|A_{\text{pred}} - A_{\text{true}}|}{A_{\text{true}}} \times 100$.

4. **Inference Latency:**
   - Per-frame latency ($p50, p90, p99$) in milliseconds on target CPU architecture (Intel Core i5 / AMD Ryzen 5 mobile).
