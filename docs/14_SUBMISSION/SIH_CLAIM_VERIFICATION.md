# SIH Claim Verification Register

## Purpose
Catalogues and audits every claim, statement, timeline reference, and evaluation framework related to the Smart India Hackathon (SIH) 2026. Prevents team members from stating unverified administrative claims or mistaking analyst models for official evaluation rubrics.

## Verification Policy
- If a parameter has not been confirmed via official SIH / AICTE / MIC release: label `UNKNOWN` or `UNVERIFIED`.
- If an evaluation framework is analyst-derived: label `ANALYST FRAMEWORK — NOT OFFICIAL SIH MARKING SHEET`.
- Zero invention of prize amounts, winner statistics, or team quotas.
